# Judge Demo (~90 s) — draft, UI not built yet

1. Landing shows a finished showcase plan for a fictional unreleased film (labelled cached/live).
2. Press **Run live**: trace streams state by state with Qloo call ids.
3. Map + market evidence panels; click a market for its claims and call details.
4. Strategy: markets, subtitle/dub, spend vs budget, independent check ✓.
5. War Room: "Remove <top market>" → invalidated decisions, reused research, new reserves, side-by-side v1/v2.
6. "Cut budget 40%" → dubs become subtitles, diff explained.
7. Evidence Lab: claim ledger by provenance, raw call log (no key), experiments.
8. Export decision memo.
Fallback: if the API is down, the cached showcase loads with a visible "cached on <date>" banner.
